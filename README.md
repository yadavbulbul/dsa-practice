# DSA, LLD, HLD & AI Practice Repository

## Overview

This repository is my personal space for improving problem-solving and software engineering skills through consistent practice and implementation. It includes Data Structures and Algorithms (DSA), Low-Level Design (LLD), High-Level Design (HLD), and Artificial Intelligence (AI) related learning and experiments.

## Learning Path

I'm following the structured curriculum from the **Striver's Complete Guide to DSA** on [Take U Forward](https://takeuforward.org/), which provides an excellent roadmap for mastering data structures and algorithmic techniques.

## Practice Areas

- **DSA**: Data structures, algorithms, recursion, dynamic programming, and interview problems
- **LLD**: Object-oriented design, design patterns, SOLID principles, and practical system components
- **HLD**: Scalable architectures, APIs, databases, distributed systems, and system design fundamentals
- **AI**: Machine learning concepts, AI tools, experiments, and practical applications

## Languages

I use **C++** for coding practice, DSA, and LLD implementations. I use **Python** for Retrieval-Augmented Generation (RAG) and AI-related learning, experiments, and projects.

## Purpose

This repository serves as:
- A personal reference for DSA concepts and solutions
- A place to practice LLD and HLD for software design and system design interviews
- A workspace for exploring AI concepts and building related projects
- A documentation of progress in mastering algorithmic thinking
- A resource for revision, interview preparation, and continuous learning
